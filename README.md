### 📻 Sistema de Agendamento de Estúdios

Projeto voltado para o gerenciamento de **reservas de estúdios de gravação de duas rádios**.

O sistema tem como objetivo organizar os horários dos estúdios, permitindo visualizar períodos disponíveis, ocupados, reservados e indisponíveis.

**Principais funcionalidades planejadas:**

* Cadastro de estúdios
* Agendamento de horários
* Controle de disponibilidade
* Validação das gravações
* Gerenciamento de técnicos
* Controle de rádios
* Histórico de reservas

**Tecnologias:**

* Python
* Django
* Banco de dados
* HTML/CSS
* API REST
